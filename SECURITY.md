# Security Policy

ShopPay Audit Benchmark is intentionally flawed. The default branch contains seeded business-logic defects for evaluation purposes.

Please do not report the documented seeded defects as private vulnerabilities. They are part of the benchmark and listed in `BENCHMARK.md` and `docs/SCORING.md`.

## What to report

Open a public issue for:

- unclear benchmark behavior
- undocumented seeded defects
- accidental dependency or supply-chain risk
- documentation that could confuse benchmark users

## Private reports

If you find a problem unrelated to the intentional benchmark cases and believe it should not be public, contact the repository maintainer through GitHub.
