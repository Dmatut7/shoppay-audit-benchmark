# Code of Conduct

ShopPay Audit Benchmark is a small technical project for evaluating business-logic audit behavior in AI coding agents.

Contributors are expected to:

- keep discussion focused on the benchmark and its documentation
- explain proposed cases with concrete business rules and reproduction steps
- review code and reports respectfully
- avoid personal attacks, harassment, spam, or off-topic promotion

Maintainers may close issues, remove comments, or block participants who disrupt the project.

If you see a problem, open an issue with a clear description and links to the relevant discussion.
